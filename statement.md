# Project Statement

## Problem Statement

Basic image processing tasks such as grayscale conversion, noise reduction, edge detection, image enhancement, and image segmentation are commonly required in computer vision applications. Performing these operations separately can be inconvenient for beginners.

This project provides a simple Image Processing System that performs multiple computer vision operations on an input image using Python and OpenCV.

## Scope

The system processes a user-provided image and generates processed outputs using standard image processing techniques.

## Target Users

- Computer Vision students
- Beginners learning image processing
- Students experimenting with OpenCV
- Users who need basic image preprocessing operations

## High-Level Features

1. Grayscale Conversion
2. Gaussian Blur
3. Canny Edge Detection
4. Histogram Equalization
5. Otsu Image Segmentation
6. Run All Operations

## Technologies Used

- Python
- OpenCV
- NumPy
- Visual Studio Code
- Git and GitHub
